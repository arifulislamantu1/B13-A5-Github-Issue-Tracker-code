1. What is the difference between var, let, and const?
=> 
i. var is function-scoped; let and const are block-scoped.

ii. var can be redeclared; let and  const cannot.

iii. var and let can be reassigned; const cannot.

iv. const allows object properties to change but not the variable itself.

v. Modern JS prefers const by default, let if reassignment is needed, and avoids var.




2. What is the spread operator (...)?
=>
The spread operator (...) expands arrays or objects into individual elements or properties, making it very handy for copying, merging, or passing multiple values.




3. What is the difference between map(), filter(), and forEach()?
=>
i. map() – transforms each element and returns a new array.

ii. filter() – selects elements by condition and returns a new array.

iii. forEach() – runs a function on each element without returning anything.





4. What is an arrow function?
=>
An arrow function in JavaScript is a shorter way to write functions using the => syntax. It allows single-line expressions without return and can have zero, one, or multiple parameters.




5. What are template literals?
=>
Template literals in JavaScript are a way to create strings more easily and flexibly using backticks ` instead of quotes (' or "). They allow embedding variables or expressions directly into strings, support multi-line strings without special characters, and enable string interpolation for dynamic content.
